# X（推特）Premium 怎么付款（要点）

> 整理时间：2026 年 10 月。价格按地区本地化，结算时可能加税，以 X 帮助中心（About X Premium）和结算页为准。[返回目录](index.md)

## 先说结论

- x.com 网页订阅**只收银行卡**，由 Stripe 处理；X 帮助中心里没有支付宝。App 里订阅走 Apple / Google 账户，价格更贵。
- 被拒最常见的：卡不支持境外美元扣款、账单地址或邮编对不上、**同一天试太多次触发 X 的每日购买次数上限**、余额不够含税金额。
- 连续失败两次就停，核对金额和地址，**第二天**再试一次。

## 三档价格（网页美国价）

| 档位 | 月付 | 年付 | 主要多了什么 |
|---|---|---|---|
| Basic | $3 | $32 | 编辑帖子、长帖和视频，没有蓝标 |
| Premium | $8 | $84 | 蓝标（审核后）、广告减少、创作者收益、Grok 用量更高 |
| Premium+ | $40 | $395 | 再加 SuperGrok、大部分地方无广告、长文 Articles |

不少地区按当地货币标价、另加税，最终以结算页为准。

## 网页还是 App 内购

- **x.com 网页**：自己填卡，价格最低，能不能过看这张卡。
- **iPhone / 安卓 App**：从 Apple ID / Google Play 扣，价格更高，被拒要去 Apple / Google 那边改。
- 在哪个平台订的就在哪个平台换卡、取消；没取消前别在另一个平台再订，会重复扣钱。

## 被拒的常见原因

| 原因 | 说明 |
|---|---|
| 发卡行拒了 | 国内卡默认不开境外线上美元交易，X 只提示付款失败 |
| 卡信息、地址、邮编填错 | X 帮助中心把这条列第一 |
| 每日购买次数上限 | 连着试几次后，当天换好卡也会失败，要等第二天 |
| 网络出口地区频繁变化 | 银行可能核对付款时的 IP，保持稳定、和账单国家一致 |
| 余额不够含税金额 | 我们卡上见过 $8 的 Premium 实扣 $8.49 |
| 续费扣在停用的卡上 | 到期自动扣原卡，卡停了每次续费都失败 |

## 排查顺序

1. 别再连着点订阅，记下报错原文和含税总额。
2. 确认余额够总额；预付卡每笔有手续费的再多留 $1。
3. 卡号、有效期、CVV、账单地址、邮编按发卡方原样填。
4. 确认 X 账号已绑定并验证手机号（订阅 Premium 需要）。
5. 失败两次就等第二天，或换卡。
6. 扣了钱没生效：等几分钟刷新，还没有就带收据从 help.x.com 联系客服。

X Premium 除法律规定外不退款；不想续了，至少在续费日前 24 小时取消。网页升级档位会立刻扣差价。
