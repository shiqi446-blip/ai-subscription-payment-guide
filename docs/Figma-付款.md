# Figma 怎么付款（要点）

> 整理时间：2026 年 10 月。价格以 figma.com/pricing 为准，价格页是税前价，结算按账单地址另加税。[返回目录](index.md)

## 先说结论

- Figma 付费计划主要用**信用卡 / 借记卡**（Visa、Mastercard、AmEx）按美元扣；PayPal 只在部分国家可用，新开 Professional 基本只能用卡，**没有支付宝**。
- 被拒最常见的：卡不支持境外美元扣款、余额不够含税金额（尤其年付）、账单地址对不上、同一张卡反复提交。
- 续费扣不上，Figma 会**最多重试 21 天**，之后团队变成只能看不能编辑；补救是重填付款方式，没有「重新付款」按钮。

## Professional 多少钱

| 席位 | 月付 | 年付（折合每月） | 适合谁 |
|---|---|---|---|
| Full | $20 | $16（一年 $192） | 设计、原型、Dev Mode 全功能 |
| Dev | $15 | $12 | 开发看标注、用 Dev Mode |
| Collab | $5 | $3 | 只用 FigJam、评论协作 |

Starter 免费版可以先试。Figma 按「付费席位人数」收钱，新加一个 Full 席位会按比例补扣；一个人用就只留自己一个付费席位。

## 绑卡订阅步骤

1. 登录 figma.com，进入团队（Team），点 Upgrade / Choose plan，选 Professional。
2. 选月付或年付、各类席位数量，核对含税总价。
3. 填卡号、有效期、CVV，账单地址按发卡方资料填，国家和卡对得上（税也按这个地址算）。
4. 确认余额够这一笔（年付要够一整年），只提交一次；成功后在团队 Settings → Billing 看下次扣款日。

## 被拒的常见原因

| 原因 | 说明 |
|---|---|
| 卡不支持境外美元扣款 | 国内借记卡、没开境外交易的信用卡直接被拒 |
| 余额不够 | 加了税，或选了年付一次扣一整年 |
| 账单地址对不上 | 国家、邮编填错，验证不通过 |
| 同一张卡反复提交 | 风控或发卡方暂时拒掉这张卡，越试越糟 |
| 付款表单加载不出来 | 换浏览器、关广告拦截插件，和卡无关 |

## 续费扣款失败怎么补

1. 看失败邮件或 Billing 里的发票，确认是哪一笔（续费、新加席位的按比例账单、首次订阅）。
2. 确认余额够「含税金额 + 卡的单笔手续费」，年付按全部付费席位一整年准备。
3. 核对卡号、有效期、CVV、账单地址。
4. 在团队 Settings 点 **Change payment method** 重填卡（原卡补了余额也重填），Figma 会马上扣所有未付账单；连续失败两三次就停手，隔一段时间再试或换卡。

用预付卡的注意：21 天里每次自动重试失败都可能被收一笔失败手续费，收到失败邮件当天就补余额或换卡。

## 常见问题

**Figma 能用支付宝付吗？** 官方没列。Organization / Enterprise 可以找销售走发票。

**扣款失败会被锁吗？** 会。最多重试 21 天，扣不上团队变只读，付款成功后恢复。
