# Claude Code 订阅付款：Pro / Max / API 三种买法和付款方式对比

> 整理时间：2026 年 10 月。价格以 [claude.com/pricing](https://claude.com/pricing) 为准，支持地区以 [Anthropic 官方列表](https://www.anthropic.com/supported-countries) 为准。[返回目录](index.md)

> 关键词：Claude Code 订阅付款、Claude Code 怎么付款、Claude Max 付款、Anthropic API 充值、Claude Code 国内付款

写这篇是因为身边几个写代码的朋友都卡在同一步：Claude Code 装好了，终端里一跑 `claude` 要登录，登录后要订阅，订阅页绑卡就提示 declined。下面是整理下来的笔记，按「先搞清楚买什么 → 为什么付不了 → 有哪些办法」的顺序写。

## 一、Claude Code 到底要付哪一笔钱

Claude Code 不单独卖，有两条计费路线：

| 路线 | 怎么登录 | 怎么付钱 | 适合谁 |
|---|---|---|---|
| 订阅（Pro / Max） | 用 claude.ai 账号登录 | 网页端按月或按年绑卡订阅；Max 有两档，额度比 Pro 高 | 个人开发者，每天固定在用 |
| API 按量（Anthropic Console） | 用 Console 生成的 API key | 先在 Console 绑卡、预充 credits，按 token 扣费 | 团队、CI、偶尔跑大任务 |

几点经验：

- 每天都在用、经常撞到额度上限的，Max 通常比 API 按量便宜；偶尔用一下，Pro 就够。
- API 路线可以在 Console 里设用量上限，建议先关掉自动充值，避免一次长任务扣掉一大笔。
- 网页端两条路线**都要绑卡**。订阅档另有一个例外：在 iOS App 里订阅，走的是苹果账单，和卡无关（见下文礼品卡一行）。

## 二、为什么国内卡付不了

1. **发卡国不在支持地区**。中国大陆和香港都不在 Anthropic 的支持地区列表里，国内银行发的卡，包括双币卡、全币种卡，发卡国都是中国，绑卡时基本过不了。
2. **三个地区对不上**：卡的发卡国、填写的账单地址、访问时的网络出口地区，三者不一致时风控会拒。
3. **连续失败被记住**：同一个账号短时间内换好几张卡重试，后面换成一张正常的卡也可能被拒。

另外要说清楚：账号本身的使用地区也要在官方支持范围内。付款成功不等于账号可以长期使用，这取决于 Anthropic 的条款和审核，任何付款工具都保证不了。本文不提供伪造地区或身份的方法。

## 三、几种付款办法对比

「成功率」是根据社区反馈做的粗略分档，不是统计数据，请自己判断。

| 办法 | 门槛 | 费用 | 成功率（经验） | 风险 / 注意 |
|---|---|---|---|---|
| 境内双币卡 / 全币种卡 | 低，多数人已经有 | 外币交易一般有货币转换费，各行不同 | 低 | 发卡国是中国，Claude 这里基本不行，多试还会留下失败记录 |
| 香港银行卡 | 中高，通常需本人赴港开户、准备地址证明 | 多数免年费，港币卡付美元有转换费 | 低到中 | 香港同样不在支持列表，港卡能不能过看具体卡段 |
| 海外银行卡（美 / 英 / 新加坡等） | 高，要当地身份、地址或本人到场 | 基本无额外费用 | 高 | 适合在当地留学或工作的人，详见[怎么有一张海外信用卡](overseas-credit-card.md) |
| 亲友代付 | 要有在海外、愿意帮忙的人 | 0 | 高 | 卡不在自己手里，续费失败、退款、换卡都要对方配合 |
| 预付虚拟卡（例：Pink Card） | 网页下单，网页面值 $110 起；支付宝扫码约 1–2 分钟自动发卡 | 开卡 $10 + 3% 服务费（按面值 + $10 计）；续充 $5 + 5%；$2.50/月；每笔 $1；支付宝付款另加 3% | 中到高，取决于卡段和账单地址是否逐字段填对 | 比海外实体卡贵；失败交易也收手续费；未用完余额不退 |
| 其他预付卡平台 | 多数要注册平台账号、做身份认证 | 开卡几美元到 $20 不等，充值费 3% 上下 | 各家差别大 | 这类平台关停过不少，选之前看运营时间和退款口碑 |
| App Store 礼品卡 + iOS 内购 | 要有外区 Apple ID，买对应地区礼品卡 | 礼品卡溢价；App 内价格可能高于网页 | 中 | 只能买订阅档，不能给 API 充 credits；退订要在苹果里操作 |

## 四、我的建议顺序

1. 有本人名下海外卡：直接网页订阅，最省钱。
2. 没有海外卡、只用订阅档：可以比较「App Store 礼品卡」和「预付虚拟卡」两条路，前者只限 iOS 内购，后者网页端和 Console 都能绑。
3. 要用 API：礼品卡帮不上，只能用能在 Console 绑定的卡。
4. 不建议买别人的账号或共享账号，出问题时没有任何追索途径。

## 五、绑卡前检查清单

- 账号使用地区在官方支持列表里；
- 账单地址照发卡方给的逐字段填，邮编、州、城市别自己改；
- 卡内余额 ≥ 订阅价 + 可能的税；预付卡还要留出月费和交易费；
- 被拒后先停：删掉失败的卡，隔几个小时核对完再绑一次，不要连续换卡重试；
- 订阅成功后，在账单页确认下次扣款日期，提前把余额备好。
