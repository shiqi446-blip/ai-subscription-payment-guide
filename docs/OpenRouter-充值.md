# OpenRouter 怎么充值（要点）

> 整理时间：2026 年 10 月。手续费、退款和过期规则以 openrouter.ai 的 FAQ 和充值页为准。[返回目录](index.md)

## 先说结论

- OpenRouter 没有月费，是**先充值买额度、调用模型时按用量扣**，额度用完就停，不会欠费。
- 官方收**主流信用卡和支付宝**，两种都收 **5.5% 手续费（最低 $0.80）**：充 $10 付 $10.80，充 $100 付 $105.50。
- 偶尔充一次、金额不大，直接用支付宝最省事；要开**自动充值（auto top-up）**，或者支付宝付不过去，才需要绑一张能付美元的卡。

## 计费规则一览

| 项目 | 规则 |
|---|---|
| 计费方式 | 预充额度，按调用量从额度里扣 |
| 充值手续费 | 卡或支付宝都是 5.5%，最低 $0.80 |
| 自动充值 | 额度低于你设的阈值时自动补一笔，**只能扣已保存的卡** |
| 退款 | 充值后 24 小时内可申请退还没用掉的额度，手续费不退 |
| 过期 | 官方保留购买一年后让未用额度过期的权利，别一次充太多 |

## 充值步骤

1. 登录 openrouter.ai，右上角头像 → **Credits**，点 **Add Credits**。
2. 填要充的美元额度，结算页会显示加上手续费后的总额，先核对这个数。
3. 用支付宝：在付款方式里选一次性付款方式，出现支付宝后扫码付。看不到支付宝的，检查弹窗里一次性付款方式的开关和账单地址是否填完整。
4. 用卡：填卡号、有效期、CVV 和账单地址，**只提交一次**。
5. 回 Credits 页确认额度到账。扣了钱但额度没到的，拿收据联系 OpenRouter 客服。

## 付款失败的常见原因

| 现象 | 常见原因 |
|---|---|
| 支付宝提示超限 | 跨境单笔有上限，一次充太多；拆成几笔小额，见 [支付宝跨境超限怎么办](alipay-cross-border-limit.md) |
| card declined / payment failed | 卡没开境外美元线上扣款，国内卡常见 |
| 余额明明够额度 | 没算手续费：卡里正好 $100 充不了 $100 额度，实际扣 $105.50 |
| 地址校验不过 | 账单地址、邮编和发卡方记录对不上 |
| 越试越不行 | 几分钟内反复提交或来回换卡，被风控当成盗刷测试 |
| 自动充值一直失败 | 保存的卡没钱或已停用，每次触发都是一次失败扣款 |

## 排查顺序

1. 先停手，记下报错原文和结算页总额。
2. 看有没有收据：没有收据就是没扣成功；有收据但额度没到，联系客服。
3. 支付宝付不过去，先确认是不是跨境单笔超限，改小金额再试一次。
4. 用卡的，确认余额够「额度 × 1.055」，卡每笔有手续费的再多留一点；账单地址按发卡方给的原样填。
5. 付款时网络出口地区保持稳定，和账单国家大致一致，付到一半别切换。
6. 连续失败两次就隔几个小时再试，或换一种付款方式。
7. 打算不用某张卡之前，先关掉自动充值、删掉卡。

## 常见问题

**OpenRouter 能用支付宝充值吗？** 能，官方 FAQ 写明收支付宝，手续费同样 5.5%（最低 $0.80）。大额可能碰到跨境单笔上限，拆成几笔。

**自动充值能用支付宝吗？** 不能。自动充值只扣已保存的卡，要开就得绑一张能付美元的卡，并保证余额够几次充值。

**充错了能退吗？** 官方写的是充值后 24 小时内可申请退还没用掉的额度，手续费不退；额度在购买一年后可能过期。
