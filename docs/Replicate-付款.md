# Replicate 怎么付款（要点）

> 整理时间：2026 年 10 月。计费规则以 Replicate 官方文档和 Billing 页为准，各模型单价看模型页。[返回目录](index.md)

## 先说结论

- Replicate 按用量计费，新账号要**先买预付额度**（prepaid credit），余额到 0 就不能开新任务。
- 额度**从购买日起一年有效、不退款**，按实际用量买，别一次买太多。
- 服务条款写的付款方式是信用卡、借记卡或银行转账，**没有支付宝**。只试几个免费模型的，先不用绑卡。

## 怎么收钱

| 项目 | 规则 |
|---|---|
| 预付额度 | 先绑付款方式、买一笔额度，调用从余额扣 |
| 余额到 0 | 新任务不启动；正在跑的任务超出余额的，月底从默认付款方式补扣 |
| 自动充值（可选） | 余额低于门槛时补到设定金额；门槛最低 $5、补到最低 $15 |
| 老账户按月后付 | 月初扣上月用量，首次超过某些额度时会提前扣一次 |

## 买额度步骤

1. 登录 replicate.com，打开 Billing。
2. 添加付款方式：卡号、有效期、CVV，账单地址按发卡方资料填。绑卡时一般有一笔 **$0 验证**，不扣钱，但卡要能扣美元。
3. 选额度金额，核对结算金额（有的地区加税），只提交一次。
4. 需要再开自动充值；不想被自动扣就别开。

## 被拒的常见原因

| 原因 | 说明 |
|---|---|
| 卡不支持境外美元扣款 | 绑卡或买额度时直接被拒 |
| 余额不够 | 买额度要整笔扣；开了自动充值也要留够每次补的钱 |
| 账单地址对不上 | 国家、邮编填错 |
| 同一张卡反复提交 | 风控或发卡方暂时拒掉这张卡 |
| 付款表单加载不出来 | 换浏览器、关广告拦截插件，和卡无关 |

## 常见问题

**必须先充值才能用吗？** 新账号基本是。少数模型能免费试，用一阵后会要求设置付款。

**额度会过期吗？能退吗？** 一年有效，不退款。
