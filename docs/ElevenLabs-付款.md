# ElevenLabs 怎么付款（要点）

> 整理时间：2026 年 10 月。价格、积分和退款规则以 elevenlabs.io/pricing 和官方帮助页为准，价格不含税。[返回目录](index.md)

## 先说结论

- ElevenLabs 在网页订阅，官方列的付款方式是**信用卡、Apple Pay、Google Pay**（UPI 只限印度），按美元扣款；**没有支付宝和 PayPal**。
- 官方专门写了：**预付卡不是直接支持的付款方式**，遇到过发卡行或 Stripe 拦截，用预付卡要自己承担被拒的风险。
- 国内卡被拒最常见的三种：卡不支持境外美元扣款、余额不够含税金额（尤其首月折扣结束那个月）、同一张卡短时间反复提交。

## 价格和积分

| 档位 | 按月 | 按年折合 | 每月积分 |
|---|---|---|---|
| Free | $0 | — | 1 万 |
| Starter | $6 | $5 / 月 | 3 万 |
| Creator | $22（新用户首月常有折扣，如半价 $11） | 约 $18.33 / 月 | 12.1 万 |
| Pro | $99 | $82.50 / 月 | 60 万 |
| Scale / Business | $299 / $990 | — | 含 3 / 10 个工作区席位 |

- 付费计划每月重置积分，没用完的**最多结转两个月**的量；Free 不结转。
- 升级立刻生效，旧计划没用完的额度带过去；降级到当前账单周期结束才生效。
- 取消后转回 Free，**没用完的积分清掉**，取消前先用掉。

## 网页绑卡步骤

1. 登录 elevenlabs.io，进入 **Subscription** 页面，选计划和按月 / 按年。
2. 核对结算页最终金额（首月折扣价、税），按年付要一次付清一整年。
3. 填卡号、有效期、CVV，账单地址按发卡方给的填，国家和卡对得上。
4. 确认余额够这一笔，**只提交一次**；成功后在 Subscription 页能看到计划、积分和下次扣款日。
5. 换卡在 **Billing** 里改付款方式，之后续费从新卡扣。

## 被拒的常见原因

| 原因 | 说明 |
|---|---|
| 卡不支持境外美元扣款 | 国内借记卡、没开境外交易的信用卡，结算页直接拒 |
| 预付卡被拦 | 官方说预付卡不在直接支持范围，部分卡段会被发卡行或 Stripe 拒，和余额无关 |
| 余额不够 | 首月折扣价扣完，第二个月按原价扣（Creator 从 $11 变 $22），或结算加了税 |
| 账单地址对不上 | 国家、邮编填错，校验不通过 |
| 反复提交 | 失败几次后风控可能暂时拒掉这张卡，越试越糟 |

## 续费失败、退款和取消

- 续费按账单周期自动扣。官方没写清自动重试几次、宽限几天，以 ElevenLabs 发的账单邮件为准。收到扣款失败邮件当天就补余额，再到 Billing 里重新付款或换卡，别等它自己重试。
- 退款：官方写的是**付款后 14 天内申请、且这期积分一点没用**，才符合条件。
- 取消订阅在当前账单周期结束时生效。

排查顺序：

1. 看失败邮件，确认是哪一笔没扣上（续费、首月折扣结束后的原价、还是升级补差价）。
2. 确认余额够「含税金额 + 每笔手续费（如有）」，按年付的准备一整年。
3. 核对卡号、有效期、CVV 和账单地址。
4. 补完余额后在 Billing 里重新付款；同一张卡连续失败两三次就停手，隔一段时间再试或换卡。

## 常见问题

**ElevenLabs 能用支付宝付吗？** 官方没有列支付宝，也没有 PayPal；帮助页写的是信用卡、Apple Pay、Google Pay。

**Creator 一个月多少钱？** 按月 $22，每月 12.1 万积分；新用户首月常有折扣，第二个月起按原价扣。按年付折合约 $18.33 / 月。

**能退款吗？** 付款后 14 天内、且这期积分一点没用才符合条件；取消在账单周期结束时生效，之后转回 Free、积分清零。
