# ChatGPT Plus / Claude Pro 订阅被拒：报错对照和 6 个自查办法（要点）

> 整理时间：2026 年 10 月。报错含义以 Stripe 拒付代码文档、OpenAI 和 Claude 帮助中心为准，各家页面会改版。[返回目录](index.md)

## 先说结论

- 两家的网页订阅都由 Stripe 收款。「Your card was declined」本身不说明原因，OpenAI 和 Anthropic 也都写明一般拿不到发卡行的具体拒付原因。
- 按报错原文先分三类：**卡本身不被接受**（只能换卡）、**钱或信息不对**（补钱、改信息）、**验证或风控没过**（完成验证、停手等一等）。
- 我们自己卡上付 ChatGPT / Claude 的失败交易里，约 65% 是余额或额度不够。先查钱，再查别的。

## 先分清在哪里付的钱

| 入口 | 谁收钱 | 被拒了去哪改 |
|---|---|---|
| chatgpt.com / claude.ai 网页 | Stripe | 本文的对照主要针对这里 |
| iPhone / 安卓 App 内购 | Apple / Google | App Store / Google Play 的付款设置 |
| OpenAI API 额度、Anthropic Console | 和订阅是两套账单 | OpenAI 写明 API 额度不收预付卡 |

## 报错对照

| 页面上的原文 / 代码 | 意思 | 怎么办 |
|---|---|---|
| Your card was declined（card_declined / generic_decline） | 被拒了，没说为什么；疑似欺诈、挂失等原因也只显示这一句 | 按下面 6 步查，查不出来问发卡行 |
| Your card does not support this type of purchase（card_not_supported） | 这张卡不支持这类消费：没开境外线上或定期扣款，或用途受限 | 问发卡行能否开通；不能就换卡，换浏览器、换账号没用 |
| insufficient_funds | 钱不够这一笔 | 标价 $20 实扣 $21–25 很常见（加税）；按「标价 × 1.25 再多留几美元」准备 |
| do_not_honor / transaction_not_allowed | 发卡行拒绝，原因未知 | 只有发卡行知道；国内卡在这一步被拒的很多 |
| incorrect_zip / incorrect_cvc / expired_card | 邮编、安全码、有效期不对 | 照发卡方资料逐字重填，地址差一个字母也可能被拒 |
| authentication_required（3D Secure 没完成） | 需要银行二次验证但没做成 | 允许弹窗、关广告拦截，验证完成前别刷新；仍失败请发卡行开通或换卡 |
| card_velocity_exceeded | 超过余额、额度或次数限制 | 先停手；预付卡提示「超过单笔 / 累计额度」多数就是余额不够 |
| processing_error | 处理出错，不一定是卡的问题 | 过一会儿再试一次 |
| 发卡国家 / 账单地区不在支持范围（通常也只显示 declined） | 两家都要求发卡国在支持地区，Claude 还要求账单地址和发卡国一致 | 改地址、换时间都没用，只能换发卡国在支持范围内的卡 |

## 我们卡上的失败原因分布

2026-04-22 到 10-15，我们自己发行的卡付 OpenAI / Anthropic 失败 977 笔（按交易号去重，不含个人信息）：

| 原因 | 占比 |
|---|---|
| 余额或额度不够 | 约 65% |
| 卡已停用或冻结，订阅还在按周期扣 | 约 27% |
| 有效期、CVV 填错 | 约 7% |
| 商户类别限制等其他 | 不到 1% |

同期所有商户失败 1,456 笔里，3D Secure 失败只有 1 笔。限制：被 Stripe 风控提前拦下的交易到不了发卡方，不在统计里；续费重试会重复计笔。

## 6 个自查办法（按顺序）

1. **先停手**：失败两次就停，连着重试会让风控更紧，很多预付卡失败也收手续费。
2. **看发卡国家和用途**：国内银行发的卡（含双币卡、全币种卡）大多在发卡国家这一项就过不去，查到这里可以直接考虑换卡。
3. **算够钱**：标价 + 税 + 绑卡时可能的小额验证；年付、Max 这类大额档位要整笔够。
4. **账单信息逐字照填**：卡号、有效期、CVV、姓名、地址、邮编都按发卡方资料。
5. **网络出口地区保持稳定、和卡一致，完成 3D Secure**：付款中途别切网络。
6. **分清入口，删掉旧卡、隔几个小时再提交一次**；还被拒就把报错原文和时间发给发卡行查。

## 常见问题

**绑卡成功了，续费却被拒？** 绑卡只说明信息过了校验，每次续费都重新扣款。最常见是余额不够标价加税，其次是卡过期或停用。

**被拒后多久能再试？** 官方没公开固定时间。查清楚、删掉旧卡、隔几个小时只提交一次。
