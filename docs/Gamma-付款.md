# Gamma 怎么付款（要点）

> 整理时间：2026 年 10 月。各档价格会调整，部分地区按账单地址加税，以 gamma.app/pricing 和结算页为准。[返回目录](index.md)

## 先说结论

- Gamma 个人付费计划**只收银行卡**（Visa、Mastercard、American Express 的信用卡和借记卡），由 Stripe 处理；帮助中心列的其他方式只有印度 UPI、巴西 Pix、印尼 GoPay，**没有支付宝**。
- 绑卡被拒最常见的：卡不支持境外美元线上扣款、账单地址对不上、余额不够**含税**金额、失败后连着重试。
- 退款窗口很短：**订阅后 3 天内**、主动联系客服、点数用量在上限以内才受理。不确定要不要长期用，先按月订。

## 档位怎么选

| 档位 | 适合谁 |
|---|---|
| Free | 一次性送 AI 点数（credits），用完不自动补，先试做一两份 |
| Plus | 个人入门付费档，每月给点数，可去掉 Gamma 水印 |
| Pro | 点数更多，可用更高级的 AI 模型和图片生成，经常做演示的人 |
| Ultra | 重度用户，点数最多 |
| Team / Business | 按人头给团队买，通常年付，管理员统一付款 |

年付比月付便宜（官方写最多约省 28%），但一次扣一整年。额外点数用完了也能单独买点数包，同样从绑定的卡上扣。

## 付款入口

1. 登录 gamma.app，点 **Upgrade**，选档位和月付 / 年付。
2. 跳到 Stripe 结算页，填卡号、有效期、CVV 和账单地址，看清**含税总额**后提交。
3. 换卡、看账单、取消：**Settings → Billing → Manage subscription**（打开 Stripe 的订阅管理页）。

## 被拒的常见原因

| 原因 | 说明 |
|---|---|
| 发卡行拒了 | 不少国内卡默认不开境外线上美元交易，页面只提示「Your card was declined」 |
| 地址对不上 | 账单地址、邮编和发卡方记录不一致，Stripe 地址核对直接拒 |
| 余额不够含税金额 | 实际扣款比标价高一点；我们卡上 Gamma 的几笔都在 $11–12 之间，多出来的大概率是税 |
| 升级补差价 | 月中从 Plus 升 Pro，按剩余天数立刻补扣差价 |
| 连着重试 | 短时间反复提交，发卡行或 Stripe 风控临时拦下 |
| 续费扣在停用的卡上 | 到期自动扣原来的卡，卡停了或没钱，每次续费都失败 |

## 排查顺序

1. 别再连着点提交，记下报错原文和结算页含税总额。
2. 确认余额够这个总额；卡每笔有手续费的再多留一点。
3. 卡号、有效期、CVV、账单地址、邮编按发卡方给的原样填。
4. 付款时网络出口地区保持稳定，和账单国家大致一致。
5. 改好后只提交一次；仍失败就换卡，或带截图联系 Gamma 客服（帮助中心右下角对话框）。

退款：Gamma 从 2025 年 12 月起只在**订阅后 3 天内**受理，要主动联系客服，取消订阅不会自动退钱；Plus 要求用掉的点数少于 200，Pro 少于 600。

## 常见问题

**Gamma 能用支付宝付吗？** 不能。帮助中心列的个人付款方式是信用卡、借记卡，以及印度 UPI、巴西 Pix、印尼 GoPay。

**扣的钱为什么比标价多？** 多数是按账单地址加的税，也可能是月中升级补的差价，以 Stripe 结算页和 Gamma 发票为准。

**订了不想用能退吗？** 只在订阅后 3 天内受理，要主动联系客服，点数用量有上限；超过 3 天只能取消下一期续费。
