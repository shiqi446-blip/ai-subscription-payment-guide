# Vercel 怎么付款（要点）

> 整理时间：2026 年 10 月。价格和政策以 Vercel 官方价格页、文档为准。[返回目录](index.md)

## 先说结论

- Vercel 只收**信用卡 / 借记卡**，按美元按月自动扣款，不收支付宝，也不收 PayPal。支持的卡组织有 Visa、Mastercard、美国运通、JCB、Discover 和**银联**——手上有能付美元的银联卡，先直接试。
- 官方文档写明礼品卡、预付卡、EBT 卡和**部分虚拟卡**不能作为付款方式，具体哪些被拒不公开。
- 续费扣款失败后 **14 天**内没补上，账号下所有部署会被暂停；新开订阅首笔要在 **24 小时**内付成功。扣款失败当天就处理。

## 什么时候扣钱、扣多少

| 项目 | 说明 |
|---|---|
| Hobby | 免费，不用绑卡 |
| Pro | 按开发席位每月收费，官方价 $20 / 月，含 $20 用量额度；只能按月付 |
| 超出额度的用量 | 按量计费，默认 $200 按需预算，快到时邮件 / 站内 / 短信提醒；月中用量涨得快可能先出一张「部分账单」 |
| v0 付费 | 同样绑卡，价格以 v0 官方价格页为准 |
| Marketplace 数据库（如 Neon） | 按用量另外出账，卡上商户名类似「VERCEL MKT NEON」，和 Pro 账单分开扣，金额可能比席位费还高 |

## 绑卡步骤

1. 登录控制台，左上角切到要付费的团队（付款方式挂在团队上）。
2. Settings → Billing → Payment Method → Add new card。
3. 填卡号、有效期、CVV，账单地址按发卡方给的填，国家和卡对得上。
4. 可能有一笔很小的临时验证扣款，之后自动撤销。
5. 换卡要先加新卡再删旧卡；发票抬头、地址、税号只对之后的新账单生效，要报销先填好再升级。

## 绑卡被拒 / 扣款失败的排查顺序

| 常见原因 | 处理 |
|---|---|
| 卡不支持境外美元扣款 | 换能按美元扣款的卡，或问发卡行开境外交易 |
| 卡的类型不被接受（预付卡、部分虚拟卡） | 换卡；预付卡先小额试绑 |
| 账单地址和卡不一致 | 按发卡方记录重填国家、邮编 |
| 余额不够当期账单 | 留够「账单 + 每笔手续费（如有）」 |
| 同一张卡短时间反复提交 | 连续失败两三次就停手，越试越糟 |

1. 在 Settings → Billing 看是哪一张账单（Pro 席位、用量、Marketplace）没扣上。
2. 确认余额够这张账单；月中用量涨得快的多留一些。
3. 核对卡号、有效期、CVV 和账单地址。
4. 在 Usage 页看用量，必要时调低按需预算或暂停用量大的项目。
5. 补余额或换卡后，回 Billing 确认欠款已付清。

## 常见问题

**Vercel 能用支付宝付吗？** 不能，只收信用卡和借记卡。

**扣款失败网站会马上下线吗？** 不会。逾期后先是不能新建项目、加成员和重新部署；14 天内没付上才暂停全部部署。

**卡上的「VERCEL MKT NEON」是什么？** Marketplace 里 Neon 数据库的用量账单。不想付了，到 Integrations / Storage 里删掉或降级。
